# Insumos funcionales

Los documentos de entrada se identifican por su función, no por códigos de curso:

1. **Ficha de la empresa** — empresa, productos, clientes, canales, procesos y problema.
2. **Ficha de comparación de ERPs** — Odoo, StarSoft, Microsoft Dynamics 365 Business Central y UBLHUB.
3. **Ficha de implementación base del ERP** — alcance, arquitectura, fases, riesgos y pruebas.
4. **Ficha RUC SUNAT** — identificación y condición tributaria de la empresa.

Los originales con datos personales o comerciales sensibles deben permanecer fuera del repositorio público. Para revisión se utiliza una copia anonimizada y autorizada.
