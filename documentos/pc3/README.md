## Fuentes documentales

La carpeta [fuentes/](fuentes/README.md) conserva cinco archivos originales: un catálogo de productos y cuatro documentos comerciales. Su índice identifica el tipo de fuente, la entidad relacionada, la utilidad para la PC3 y su clasificación como evidencia empresarial o referencia externa.

El catálogo permite estudiar el surtido y la identificación de productos para orientar el abastecimiento y la reposición. Las cartas de Guangdong Xuying, Meicanxin y Shenzhen Gearforce sustentan el análisis documental de compras internacionales y condiciones de pago relacionadas con MYS Hermanos. La factura comercial cuyo consignatario es IMPORTACIONES SOTMA S.A.C. se utiliza exclusivamente como referencia externa; no confirma que SOTMA sea proveedor de MYS Hermanos.

Los archivos se conservan sin modificar su contenido, con nombres estables en `documentos/pc3/fuentes/` para los enlaces del informe Word `GE703_PC3_Informe_G7_MYS_Hermanos_MEJORADO.docx`. Esta incorporación mantiene los aportes existentes de PC3 y la trazabilidad de PC1, PC2 y el parcial.
