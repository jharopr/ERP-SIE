# Datos

- [PC2: modelo, diccionario y controles](pc2-modelo-y-controles.md): cliente, lead/oportunidad, cotización/versionado, aceptación, solicitud y trazabilidad. Es la vista vigente para el incremento comercial; el modelo siguiente conserva la línea base operativa de PC1.

- [Inventario de fuentes y tratamiento](inventario-fuentes.md): campos mínimos, procedencia, datos sintéticos y privacidad.
- [Modelo de datos](modelo-datos.md): Entidades, relaciones y diagrama ER del proyecto.
- [Simulación del modelo de datos](simulacion-modelo-datos.md): Prueba de estrés paso a paso que valida la integridad de las relaciones en un escenario de facturación electrónica.

El diccionario establece los campos mínimos. Los identificadores técnicos los genera Odoo y los formatos de intercambio corresponden al contrato de la API de UBLHUB usado en la implementación.
