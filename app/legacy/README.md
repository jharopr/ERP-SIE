# Referencias históricas · portal retirado

Estos archivos documentan la interfaz anterior y sus comprobaciones. No se montan en Nginx, no son la entrada del sistema y sus guías no describen el flujo vigente. La documentación actual está en [app/README.md](../README.md).

El backend `/panel` solo se habilita en pruebas históricas mediante `ENABLE_LEGACY_PORTAL=true`; está deshabilitado por defecto. W1/W2/W3 también están despublicados. Las rutas actuales, reglas y roles se verifican con `scripts/verificar_odoo.py` y `scripts/probar_n8n.py`.
